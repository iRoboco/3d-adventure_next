# 3D Adventure Next

## Описание проекта
**3D Adventure Next** — это игра в стиле Minecraft, написанная на C++20 с использованием игрового движка **Axmol 2.11**. Проект фокусируется на высокопроизводительном рендере воксельного мира и поддерживает современные графические и архитектурные архитектурные подходы.

## Основные возможности
- **Управление чанками**:
  - Построение и рендеринг геометрии чанков (Chunk Meshes) c такими оптимизациями, как отсечение невидимых граней (*Face Culling*) и триангуляция.
  - Кросс-чанковая проверка соседей для устранения щелей на границах.
  
- **Физика и взаимодействие**:
  - Реализация первых штук коллизий через [`VoxelCollisionResolver`](Source/VoxelCollisionResolver.h).
  - Поддержка игрового персонажа с использованием First-Person controller на базе одного собственных обработчиков событий.
